## 📖 路线图简介与初衷

在进入大学计算机及相关专业学习时，很多初学者常常面临严重的**信息差与方向迷茫**：
- *“刚入学到底先学什么？要不要学 Git 和 Linux？”*
- *“每天在 B 站收藏了许多视频教程，敲代码却依然无从下手？”*
- *“都说要搞科研、进实验室、打大创挑战杯，可学术论文究竟怎么读？LaTeX 怎么用？”*
- *“专业核心课（数据结构、操作系统、网络、计组）浩如烟海，工业界技术日新月异，怎样兼顾扎实内功与前沿实战？”*

为了帮助同学们在自学与科研的路上少走弯路，**智锐科创协会**整理并推出了这份**「计算机技能成长与学术科研通关路线图」**。

我们坚持**“工程落地与学术科研双轨驱动”**，将大学期间关键的技术工具、核心编程语言、专业四大件、工业界主流方向与学术科研启蒙系统化拆解为 6 个清晰的通关阶段，每个技能点均配有**公认口碑最佳的优质公开课/文档外链**以及**动手实操小挑战**。

## 💡 智锐自学与科研防坑四原则

在漫长的计算机自学旅程中，请牢记以下四条心法：

1. **拒绝只当“视频收藏家”**：看 10 小时视频，不如亲手敲 2 小时代码、查 5 次报错。路线图中的每个节点都附带了“通关实战挑战”，动手做出来才算真正学会。
2. **摆脱“配环境”内耗**：初学时环境配置报错很正常，优先使用主流稳定的工具链（如 VS Code、Linux WSL、Docker），学会看官方文档和终端报错日志，不要在配环境的泥潭里消耗学习热情。
3. **重视计算机专业四大件**：前端框架和工具库层出不穷，但底层的数据结构、操作系统、体系结构和网络几十年未变。内功深厚，学任何新技术都如同降维打击。
4. **提前建立学术科研意识**：早看顶会论文、早学 LaTeX 排版、尽早了解实验室和大创申报，将让你在未来的保研、申研和科研深造中占得先机。

## 🎯 路线图主要功能与使用指南

- 🔄 **双视图自由切换**：支持**关卡闯关流（Adventure View）**与**模块全景树（Grid View）**，满足按部就班通关与按图索骥查找两种学习习惯。
- 🔗 **全网精选外链直达**：每个技能点精选经过真实口碑检验的免费公开课（如浙大翁恺、王道、蒋炎岩、左程云等）、权威中文文档与官方指南。
- 📝 **渐进式实战任务**：告别好高骛远，每个技能点设计了清晰友好的实践小挑战，边做边掌握。
- 📊 **纯前端本地持久化**：打卡进度自动保存于本地浏览器，无须注册账号，关机断网不丢失。
- 🔗 **专属打卡进度分享（URL Hash）**：支持将你的打卡成就压缩编码为专属链接，随时跨设备同步，或一键发给同学、学长把脉自学进度。
